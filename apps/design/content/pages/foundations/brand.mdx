NoteKit's brand is deliberately quiet — a single diagonal slash. It's the same mark used as
the app's logo and favicon, and it follows the monochrome rule: near-black on light, near-white
on dark. No color, no gradient, no wordmark lockup with a symbol box.

## The mark

The mark is a single stroke — a slash rising left-to-right — drawn in a 32×32 box with a round
cap. It inherits the current text color (`currentColor`), so it always reads as the neutral
[accent](/foundations/color) of whatever surface it sits on.

## The wordmark

"Notekit" is set in the product UI font (Inter), bold, with `-0.025em` tracking. When paired
with the section it belongs to, the qualifier ("Design", "Docs") follows in a lighter weight.

## Usage

- **Monochrome only.** The mark is never colored, gradient-filled, or placed on a busy
  background. If a surface needs contrast, change the surface, not the mark.
- **Give it room.** Keep clear space around the mark equal to at least the height of the stroke.
- **Don't reconstruct it.** Use the provided SVG; don't rotate, skew, or add a second slash.
- **Emoji are never a substitute** — see [Icons](/foundations/icons).
