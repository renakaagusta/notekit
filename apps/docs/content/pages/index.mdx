**NoteKit** is a notes and tasks app built on three ideas:

- **Git-backed** — every note, task, and secret is a Markdown file in a Git repository. Your
  history, attribution, and audit trail are plain Git; there is no proprietary database to be
  locked into.
- **End-to-end encrypted** — content is encrypted on your device before it is ever stored. The
  server holds ciphertext it cannot read.
- **MCP-first** — anything you can do in the app, an agent can do too, through the same
  interfaces. NoteKit ships a Model Context Protocol server and a CLI alongside the web,
  desktop, and mobile apps.

## One product, every surface

NoteKit runs on the web (`app.notekit.online`), desktop (Electron), and mobile (iOS/Android),
plus a terminal CLI and an MCP server for agents. They are separate front-ends over the same
vault — sign in on any of them and you see the same notes.
