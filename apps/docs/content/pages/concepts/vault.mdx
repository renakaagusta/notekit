title: The vault
description: Your notes, tasks, and secrets are Markdown files in a Git repository.
---

A **vault** is a Git repository. Every note is a Markdown file; every task and secret is a file
too. Because the store is just Git:

- **History is Git history.** Every change is a commit. You can see what changed, when, and by
  which device or agent.
- **Attribution is the commit author.** When an agent writes to your vault, the commit records
  that it was the agent — not you.
- **There is no lock-in.** Clone the repository and you have all of your data in an open format.

One vault can hold many **projects**, each under `projects/<slug>/`. Top-level `notes/` and
`tickets/` hold personal or cross-project items.

## Where the repository lives

By default your vault is hosted on NoteKit's managed Git service (`git.notekit.online`, powered
by Forgejo). If you self-host, you point NoteKit at your own Git backend — see
[Self-hosting](/self-hosting).

## Sync

Each surface (web, desktop, mobile, CLI) pulls and pushes to the vault. Content is transferred as
ciphertext and cached locally, so the apps stay fast and keep working across reconnects.
