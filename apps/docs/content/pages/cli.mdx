title: CLI

---

The NoteKit CLI is a terminal surface over your vault. It does full end-to-end encryption like the
web, desktop, and mobile apps — the agent surface is never plaintext-only.

## Install

```bash
npm install -g @notekit/cli
```

## Authenticate

```bash
notekit login
```

This pairs the CLI to your account as a device, with its own encryption key.

## Everyday commands

```bash
notekit notes list
notekit notes new "Meeting notes"
notekit notes search "roadmap"
notekit tasks list
notekit devices list
```

## Headless / server use

For non-interactive environments (CI, a server, an oracle agent), authenticate with a token
instead of the interactive flow:

```bash
NOTEKIT_TOKEN=... notekit notes list
```

In this mode the CLI runs without a keychain, which is what lets it run unattended on a server.

## Relationship to MCP

The CLI also embeds the [MCP server](/mcp), so a single install gives you both the terminal
commands and the agent interface. Both call the same use cases as the app — see
[agent parity](/mcp#agent-parity).
