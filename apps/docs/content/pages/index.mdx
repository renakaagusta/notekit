---

**NoteKit** is a notes and tasks app built on three ideas:

- **Git-backed** — your vault is a Git repository; history and attribution are plain Git, with no
  proprietary database to lock you in.
- **End-to-end encrypted** — content is encrypted on your device; the server only ever holds
  ciphertext it cannot read.
- **MCP-first** — anything you can do in the app, an agent can do too, through the same interfaces.

Sign in on the web, desktop, mobile, CLI, or an MCP server and you're looking at the same vault.
