title: Switch
description: Immediate on/off settings.
---

Switches toggle a single setting that takes effect immediately — no save step. The track fills
with the neutral accent when on. Try them:

<SwitchShowcase />

## Tokens

Track `32×18px`, [`full`](/foundations/radius) radius, `150ms` [transition](/foundations/motion),
on-state fill from [`primary`](/foundations/color).

## Guidance

- Use a switch only when the effect is instant. If the change needs a confirm or save, use a
  [checkbox](/components/checkbox).
- Label the setting, not the state — "Offline mode", not "On".
